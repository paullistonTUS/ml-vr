What the kernel trick adds

Here the extra coordinate is built by hand and the plane is fitted by logistic regression on the lifted points. An SVM never builds φ at all. It only needs dot products between points, and a kernel returns φ(x)·φ(z) straight from the original coordinates.

Real kernels add many coordinates at once (the RBF kernel's feature space is infinite-dimensional), so treat the 3D picture as an intuition aid rather than the full story.
